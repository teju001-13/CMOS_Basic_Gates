CMOS Inverter Design | Cadence Virtuoso | GPDK 45nm technology

Excited to share my first CMOS standard cell design developed using Cadence Virtuoso with the GPDK 45nm technology library.

The CMOS inverter is the most fundamental building block in digital VLSI design. It converts a logic HIGH to a logic LOW and vice versa, serving as the foundation for implementing more complex digital circuits.

Boolean Expression: Y = A'

Truth Table: | Input | Output | | A | Y | | 0 | 1 | | 1 | 0 |

✨Design Overview:

➡️CMOS transistor-level schematic design using PMOS and NMOS transistors. ➡️Implemented using Cadence Virtuoso with the GPDK 45nm technology library. ➡️Functional verification through Transient Analysis. ➡️Physical layout implementation following CMOS layout design practices. ➡️DRC Clean and LVS Verified.

Designing the CMOS inverter gave me hands-on exposure to the Cadence Virtuoso design environment and strengthened my understanding of CMOS technology,transient response, and the complete schematic-to-layout verification flow. Working with simulations and parametric analysis made the design process even more insightful. Looking forward to building more CMOS standard cells and expanding my knowledge of VLSI design.
